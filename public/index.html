Connect AI agents to real-time US business data

Give Claude, ChatGPT, and any MCP-compatible AI agent the ability to search Secretary of State records across all 53 US jurisdictions in real time.

Quick Setup

Claude Desktop / claude_desktop_config.json
// Add to mcpServers in your config
{
  "opensosdata": {
    "url": "https://mcp.opensosdata.com/mcp"
  }
}
Claude Code
claude mcp add opensosdata https://mcp.opensosdata.com/mcp
Cursor / VS Code
// .cursor/mcp.json or .vscode/mcp.json
{
  "servers": {
    "opensosdata": {
      "url": "https://mcp.opensosdata.com/mcp"
    }
  }
}

Available Tools

search_business_entity
Search for a US business entity by name in a specific state. Returns entity name, ID, status, type, registered agent, and address.
check_entity_status
Verify if a business entity is active, inactive, or dissolved. Ideal for KYB compliance, due diligence, and vendor verification.
batch_search
Search for multiple business entities simultaneously across different states. Up to 10 entities per batch.
list_supported_jurisdictions
Returns all 53 US jurisdictions with live coverage, including all 50 states, DC, Puerto Rico, and US Virgin Islands.
get_jurisdictions_for_region
Get jurisdictions in a specific US region. Useful for multi-state compliance checks and regional coverage.
get_account_balance
Check your current credit balance and remaining lookups. Returns a link to add funds when needed.
